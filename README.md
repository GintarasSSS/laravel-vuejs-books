## Application Boot

- ```composer install```
- ```cp .env.example .env```
- ```php artisan key:generate```
- ```./vendor/bin/sail up -d```
- ```./vendor/bin/sail artisan test```
- ```./vendor/bin/sail artisan migrate:fresh --seed```
- ```./vendor/bin/sail npm install```
- ```./vendor/bin/sail npm run prod```
